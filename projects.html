01 AI Agents / Context Compaction / Rust

AutoHarness

My current research focuses on task-adaptive context compaction for long-running coding agents: how can an agent shorten its working history while preserving the information it needs to finish a task?

I am investigating policies that condense completed subtasks and retain unresolved requirements, relevant evidence, and details needed for upcoming actions. A central question is what happens to information needed much later: a summary can support the next step yet lose a constraint that matters before the task is done.

AutoHarness is the Rust agent runtime supporting this research. I plan to compare summarization, tool-output removal, and adaptive policies on extended coding tasks, holding the model, tools, and context budget fixed. I will measure task completion, token usage and cost, elapsed time, and mistakes caused by lost information across repeated compaction. This work is in progress.

02 TypeScript / Browser Extension

Pointnote

A Chrome and Edge extension for attaching written or spoken feedback to specific page elements, then handing that context to a coding or research agent.

I built it to turn design and research observations into actionable notes with selected text, screenshots, and target context. Notes stay in the browser, can be grouped into review sessions, and export as Markdown or a ZIP bundle for an agent handoff.

04 LLM Systems / CUDA / Benchmarking

DecodeBench

A GPU inference research platform for Qwen3-family models, combining validated serving paths, reproducible benchmarks, and custom CUDA prototypes.

I use it to evaluate Qwen3.5 0.8B across Transformers and vLLM, measuring latency, throughput, memory, token parity, continuous batching, and multi-agent load. It also includes a custom Qwen3 decode-attention kernel and an experimental exact-window plus compressed-memory path for long contexts.
